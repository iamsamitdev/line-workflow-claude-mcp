# LINE Workflow Automation with Claude Code & MCP

## สร้างระบบแจ้งเตือน สรุปแชทกลุ่ม และรายงานอัตโนมัติบน LINE ด้วย AI Agent สำหรับองค์กรไทย (หลักสูตรอบรมออนไลน์เชิงปฏิบัติการ 2 วัน)

**รูปแบบ:** อบรมออนไลน์สดผ่าน Zoom - Workshop ลงมือทำจริงทุกหัวข้อ พร้อมบันทึกวิดีโอย้อนหลัง
**วันที่อบรม:** วันเสาร์ที่ 8 - วันอาทิตย์ที่ 9 สิงหาคม 2569 (2 วัน)
**เวลา:** 20:30 - 23:30 น. (วันละ 3 ชั่วโมง รวม 6 ชั่วโมง)
**ผู้สอน:** อ.สามิตร โกยม
**ประสบการณ์:** สอนและพัฒนาซอฟต์แวร์กว่า 15 ปี

## แนวคิดหลักของหลักสูตร

องค์กรไทยแทบทุกแห่งใช้ LINE เป็นช่องทางสื่อสารหลัก ทั้งไลน์ส่วนตัว ไลน์กลุ่มทีมงาน และ LINE Official Account แต่การสื่อสารเหล่านั้นยังเป็น "งานมือ" เกือบทั้งหมด ไม่ว่าจะเป็นการแจ้งประกาศภายใน การสรุปประชุมจากแชทกลุ่ม การติดตามงานที่มอบหมายกันในไลน์ หรือการทำรายงานส่งผู้บริหารทุกเช้า

ในปี 2026 สิ่งเหล่านี้เปลี่ยนไปแล้ว เมื่อ LINE เปิดตัว **LINE Bot MCP Server** ซึ่งเป็น MCP อย่างเป็นทางการที่เชื่อม AI Agent เข้ากับ LINE Official Account ได้โดยตรง ทำให้เราสามารถสั่งงานด้วยภาษาไทยธรรมดา เช่น "สรุปแชทกลุ่มวันนี้แล้วส่งกลับเข้ากลุ่ม" หรือ "ทำรายงานยอดขายเมื่อวานส่งเข้ากลุ่มผู้บริหารทุกเช้า 8 โมง" แล้วให้ AI Agent อย่าง Claude Code หรือ GPT Codex ลงมือทำให้จริงตั้งแต่ต้นจนจบ

หลักสูตรนี้พาผู้เรียนสร้างระบบ Auto Workflow บน LINE แบบครบวงจร ตั้งแต่การเชื่อม MCP Server การส่งข้อความและ Flex Message การเก็บบทสนทนากลุ่มลงฐานข้อมูล การให้ AI วิเคราะห์และสรุป ไปจนถึงการตั้งเวลารันรายงานอัตโนมัติทุกวันโดยไม่ต้องมีคนสั่ง โดยทุก Workshop ออกแบบจาก use case จริงขององค์กรไทย และ prompt ทั้งหมดออกแบบให้เป็นกลาง ใช้ได้ทั้ง Claude Code และ GPT Codex

## วัตถุประสงค์ของหลักสูตร

- เพื่อให้ผู้เข้าอบรมเข้าใจแนวคิด AI Agent และ Model Context Protocol (MCP) และมองเห็นภาพการนำไปประยุกต์ใช้กับงานองค์กรที่สื่อสารผ่าน LINE
- เพื่อให้สามารถตั้งค่า LINE Official Account, Messaging API และเชื่อม LINE Bot MCP Server เข้ากับ Claude Code ได้ด้วยตนเองตั้งแต่ศูนย์
- เพื่อให้สามารถสั่ง AI ส่งข้อความ แจ้งเตือน broadcast และสร้าง Flex Message รวมถึง Rich Menu สำหรับงานสื่อสารภายในองค์กร เช่น งาน HR และประกาศบริษัท
- เพื่อให้เข้าใจข้อจำกัดของ LINE Messaging API (อ่านแชทย้อนหลังไม่ได้) และสามารถออกแบบสถาปัตยกรรม Webhook + ฐานข้อมูล เพื่อเก็บบทสนทนากลุ่มมาให้ AI วิเคราะห์ได้
- เพื่อให้สามารถสร้างระบบสรุปแชทกลุ่ม ติดตามงานที่มอบหมายในไลน์ และส่งสรุปกลับเข้ากลุ่มโดยอัตโนมัติ
- เพื่อให้สามารถสร้างระบบรายงานธุรกิจประจำวันจากฐานข้อมูล ส่งเป็น Flex Message เข้ากลุ่มผู้บริหาร และตั้งเวลารันอัตโนมัติด้วย Task Scheduler
- เพื่อให้เขียน prompt สั่งงานที่นำไปใช้ได้กับ AI Agent หลายตัว ทั้ง Claude Code และ GPT Codex พร้อมเข้าใจความต่างของการตั้งค่า MCP ในแต่ละเครื่องมือ
- เพื่อให้ตระหนักถึงประเด็น Privacy, ความยินยอม และ Governance ของการนำข้อมูลแชทและข้อมูลธุรกิจมาประมวลผลด้วย AI

## จุดเด่นของหลักสูตร

- **ใช้ MCP อย่างเป็นทางการจาก LINE:** สอนด้วย line-bot-mcp-server (v0.5.0) ของ LINE โดยตรง ครอบคลุมเครื่องมือทั้ง 12 ตัว ตั้งแต่ push, broadcast, Flex Message ไปจนถึง Rich Menu และ get_follower_ids
- **Use Case องค์กรไทยแท้จริง:** ทุก Workshop ตั้งต้นจากงานที่องค์กรไทยทำผ่าน LINE อยู่ทุกวัน ได้แก่ แจ้งเตือน HR และประกาศภายใน, สรุปแชทกลุ่มพร้อมติดตามงาน และรายงานธุรกิจอัตโนมัติเข้ากลุ่มผู้บริหาร
- **ครบทั้งขาส่งและขารับ:** ไม่ใช่แค่สั่ง AI ส่งข้อความ แต่สร้างระบบ Webhook เก็บแชทกลุ่มลง PostgreSQL ให้ AI อ่านผ่าน MCP แล้ววิเคราะห์ตอบกลับ เป็นสถาปัตยกรรมที่นำไปใช้งานจริงได้ทันที
- **จบคอร์สได้ระบบอัตโนมัติจริง:** Capstone ปิดท้ายด้วยรายงานประจำวันที่รันเองทุกเช้าด้วย Task Scheduler โดยไม่ต้องมีคนสั่ง เปลี่ยนจาก "สั่ง AI ทีละครั้ง" เป็น "ระบบทำงานแทนเรา"
- **AI Agent เป็นกลาง ไม่ผูกติดเครื่องมือเดียว:** ใช้ Claude Code เป็นเครื่องมือหลัก พร้อม session สาธิตการใช้ prompt ชุดเดียวกันบน GPT Codex และเปรียบเทียบการตั้งค่า MCP ของทั้งสองค่าย
- **เหมาะกับผู้เรียนหลายระดับ:** ทุก Workshop มี prompt สำเร็จรูปให้ copy ใช้ได้ทันที ผู้ที่เขียนโค้ดไม่คล่องทำตามได้ครบทุกขั้น ส่วน Developer มีโจทย์ท้าทายต่อยอดให้ทุกช่วง

- นักพัฒนา โปรแกรมเมอร์ และเจ้าหน้าที่ IT ที่ต้องการสร้างระบบอัตโนมัติบน LINE ให้องค์กรของตนเอง

- วิทยากร อาจารย์ และผู้สนใจทั่วไปที่ต้องการเรียนรู้ Model Context Protocol (MCP) ผ่านตัวอย่างที่จับต้องได้จริง

## Workshop ตลอดหลักสูตร: บริษัทจำลอง "สยามสมาร์ทเทรด"

ทุก Workshop ร้อยเรียงอยู่บนสถานการณ์เดียวกันคือบริษัทซื้อขายสินค้าแห่งหนึ่งในไทยที่สื่อสารกันผ่าน LINE เป็นหลัก ผู้เรียนจะสวมบทเจ้าหน้าที่ผู้สร้างระบบอัตโนมัติให้ 3 ฝ่าย

- **ฝ่าย HR และธุรการ** - แจ้งเตือนวันหยุด นัดประชุม ประกาศบริษัท และข่าวสารภายใน ผ่าน LINE ส่วนตัวและ broadcast (Workshop Day 1)
- **ทีมปฏิบัติการ** - เก็บบทสนทนาไลน์กลุ่มของทีม ให้ AI สรุปประชุม หาว่าใครรับงานอะไรไป แล้วส่งสรุปพร้อมรายการงานกลับเข้ากลุ่มทุกเย็น (Workshop Day 2 ช่วงแรก)
- **ผู้บริหาร** - รายงานยอดขายและตัวเลขสำคัญจากฐานข้อมูล ส่งเป็น Flex Message เข้ากลุ่มผู้บริหารอัตโนมัติทุกเช้า พร้อมแจ้งเตือนรายการผิดปกติ (Capstone Day 2)

> ใช้ข้อมูลจำลองทั้งหมด (มีไฟล์ seed ฐานข้อมูลเตรียมให้) ไม่เกี่ยวข้องกับข้อมูลจริงของบริษัทใด และย้ำแนวปฏิบัติเรื่องความยินยอมก่อนเก็บข้อมูลแชททุกครั้ง

## สิ่งที่ผู้เรียนจะได้ลงมือทำจริง

- สร้าง LINE Official Account และเปิดใช้ Messaging API ของตัวเองตั้งแต่ศูนย์
- เชื่อม LINE Bot MCP Server เข้ากับ Claude Code และสั่งส่งข้อความเข้า LINE ด้วยภาษาไทยประโยคเดียว
- สั่ง AI ออกแบบและส่ง Flex Message แจ้งเตือนภายในองค์กรที่สวยงาม พร้อมทดสอบผ่าน Flex Message Simulator
- สร้าง Rich Menu ของ LINE OA ด้วยการสั่งงาน AI แทนการออกแบบเองทั้งหมด
- สร้าง Webhook Server เก็บข้อความจากไลน์กลุ่มลง PostgreSQL โดยให้ Claude Code เขียนโค้ดให้ทั้งหมด
- สั่ง AI วิเคราะห์บทสนทนากลุ่ม สรุปประเด็น หางานที่มอบหมาย แล้วส่งสรุปกลับเข้ากลุ่มเป็น Flex Message
- สร้างสคริปต์รายงานธุรกิจประจำวันจากฐานข้อมูลจำลอง และตั้งเวลารันอัตโนมัติทุกเช้าด้วย Task Scheduler
- ทดลองใช้ prompt ชุดเดียวกันบน GPT Codex และตั้งค่า MCP ฝั่ง Codex CLI ด้วยตนเอง

# Day 1 (เสาร์ 8 ส.ค.): เชื่อม AI Agent เข้า LINE ด้วย MCP + งานแจ้งเตือนองค์กร

## เป้าหมายของวันแรก

ผู้เรียนจะเข้าใจภาพรวมของ AI Agent และ MCP มี LINE Official Account ของตัวเองที่เชื่อมกับ Claude Code สำเร็จ และสั่งงานส่งข้อความ แจ้งเตือน broadcast, Flex Message และ Rich Menu สำหรับงานสื่อสารภายในองค์กรได้จริงก่อนจบคลาส

### Session 1: จาก AI Chat สู่ AI Agent และ MCP (20:30 - 21:00)

- ทำไมองค์กรไทยควรเริ่ม Auto Workflow ที่ LINE - ภาพรวม use case จริงในองค์กร
- AI Agent คืออะไร ต่างจาก AI Chat อย่างไร - รู้จัก Claude Code และ GPT Codex
- Model Context Protocol (MCP) - มาตรฐานเชื่อม AI เข้ากับระบบภายนอก และตำแหน่งของ LINE Bot MCP Server ในภาพใหญ่
- เจาะเครื่องมือทั้ง 12 ตัวของ line-bot-mcp-server: ขาส่งข้อความ (push / broadcast / flex), ขาข้อมูล (get_profile / get_follower_ids / get_message_quota) และชุด Rich Menu
- ข้อจำกัดสำคัญที่ต้องรู้ก่อนออกแบบระบบ: Messaging API อ่านแชทย้อนหลังไม่ได้ และโควต้าข้อความของแต่ละแพลน

### Session 2: ตั้งค่า LINE OA และเชื่อม MCP เข้ากับ Claude Code (21:00 - 21:40)

- สร้าง Provider และ Messaging API Channel ใน LINE Developers Console
- ตั้งค่า LINE OA Manager: เปิด Webhook, ปิด Auto-response และอนุญาตให้บอทเข้ากลุ่ม
- ออก Channel Access Token อย่างปลอดภัย และแนวปฏิบัติการเก็บ Token ไม่ให้รั่วไหล
- ลงทะเบียน line-bot MCP เข้ากับ Claude Code ด้วยคำสั่ง claude mcp add และตรวจสอบสถานะด้วย /mcp
- ทดสอบส่งข้อความแรกเข้า LINE ตัวเองด้วย prompt ภาษาไทยประโยคเดียว (moment แรกของคลาส)

**Workshop 1 (21:40 - 22:20): HR Notification Bot - แจ้งเตือนงานบุคคลและประกาศภายใน**

สวมบทฝ่าย HR ของสยามสมาร์ทเทรด สั่ง AI ทำงานสื่อสารภายในผ่าน LINE ครบวงจร ได้แก่ ส่งข้อความแจ้งนัดประชุมรายบุคคล ดึงรายชื่อผู้ติดตาม OA ด้วย get_follower_ids ส่งประกาศวันหยุดบริษัทแบบ broadcast ถึงพนักงานทุกคน และออกแบบ Flex Message ประกาศรับสมัครงานภายในที่มีปุ่มกดสมัครได้ พร้อมตรวจโควต้าข้อความคงเหลือด้วย get_message_quota

*พักเบรก 10 นาที (22:20 - 22:30)*

**Workshop 2 (22:30 - 23:10): Rich Menu องค์กร + สนามทดลอง GPT Codex**

- สั่ง AI สร้าง Rich Menu ของ OA ให้เป็นเมนูบริการพนักงาน เช่น ปุ่มดูประกาศ ปุ่มติดต่อ HR ปุ่มเว็บไซต์บริษัท ด้วยเครื่องมือ create_rich_menu แล้วตั้งเป็นเมนูหลักของบัญชี
- Cross-check Session: ตั้งค่า line-bot MCP บน Codex CLI (ไฟล์ config.toml) แล้วรัน prompt ชุดเดียวกับ Workshop 1 เปรียบเทียบผลลัพธ์ วิธีคิด และข้อแตกต่างระหว่าง Claude Code กับ Codex
- หลักการเขียน prompt สั่งงานให้เป็นกลาง ใช้ได้กับ AI Agent ทุกตัว

### สรุปวันแรกและเตรียมพร้อมวันที่สอง (23:10 - 23:30)

# Day 2 (อาทิตย์ 9 ส.ค.): Auto Workflow เต็มระบบ - เก็บแชทกลุ่ม สรุปงาน และรายงานอัตโนมัติ

## เป้าหมายของวันที่สอง

ผู้เรียนจะสร้างระบบครบวงจรที่มีทั้งขารับและขาส่ง: เก็บบทสนทนาไลน์กลุ่มลงฐานข้อมูล ให้ AI วิเคราะห์และสรุปส่งกลับเข้ากลุ่ม และปิดท้ายด้วยระบบรายงานธุรกิจประจำวันที่ตั้งเวลารันอัตโนมัติโดยไม่ต้องมีคนสั่ง

### Session 3: สถาปัตยกรรม Auto Workflow แบบครบวงจร (20:30 - 20:45)

- ทบทวนข้อจำกัด "บอทอ่านแชทย้อนหลังไม่ได้" และคำตอบเชิงสถาปัตยกรรม
- โครงสร้าง 4 ส่วนที่จะสร้างวันนี้: Webhook (ขาเข้า) + PostgreSQL (หน่วยความจำ) + Postgres MCP (ขาอ่าน) + LINE Bot MCP (ขาส่งกลับ)
- แนวคิดสำคัญ: งาน ad-hoc ใช้ MCP สั่งสด ส่วนงานประจำใช้สคริปต์ + ตั้งเวลา และ AI Agent คือคนเขียนสคริปต์ให้เราทั้งสองแบบ

**Workshop 3 (20:45 - 21:35): Group Chat Recorder - เก็บแชทกลุ่มลงฐานข้อมูล**

เชิญบอทเข้าไลน์กลุ่มทดสอบของแต่ละทีม แล้วให้ Claude Code สร้าง Webhook Server (Node.js + Express + @line/bot-sdk) ที่รับข้อความจากกลุ่มและบันทึกลง PostgreSQL ด้วย prompt สำเร็จรูปที่เตรียมให้ เปิดระบบสู่ HTTPS ด้วย ngrok ตั้งค่า Webhook URL ใน LINE Developers Console จากนั้นให้สมาชิกกลุ่มคุยกันจริงในหัวข้อจำลอง (วางแผนงานของทีมปฏิบัติการ) และตรวจว่าข้อความไหลเข้าฐานข้อมูลครบถ้วน

**Workshop 4 (21:35 - 22:05): AI สรุปประชุมกลุ่มและติดตามงาน ส่งกลับเข้ากลุ่ม**

เชื่อม Postgres MCP เข้ากับ Claude Code แล้วสั่งงานวิเคราะห์ด้วยภาษาไทย ได้แก่ สรุปว่ากลุ่มคุยเรื่องอะไร ใครเสนอประเด็นไหน วิเคราะห์ว่าใครพูดมากที่สุด ค้นหาการนัดหมายและงานที่มีคนรับปากไปทำเป็นตารางติดตามงาน แล้วปิดท้ายด้วยไฮไลท์สำคัญ: สั่งให้ AI สรุปประชุมพร้อมรายการงานค้าง ส่งกลับเข้ากลุ่มเป็น Flex Message รายงานประจำวันที่ทุกคนในกลุ่มเห็นพร้อมกัน

*พักเบรก 10 นาที (22:05 - 22:15)*

**Workshop 5 - Capstone (22:15 - 23:00): Executive Daily Report - รายงานธุรกิจอัตโนมัติเข้ากลุ่มผู้บริหาร**

- Import ฐานข้อมูลยอดขายจำลองของสยามสมาร์ทเทรด (ไฟล์ seed เตรียมให้ ข้อมูลย้อนหลัง 30 วัน สดเสมอทุกครั้งที่ import)
- Warm-up: สั่ง AI วิเคราะห์ผ่าน MCP เช่น ยอดขายเมื่อวานแยกตามสาขาและช่องทาง พร้อมโจทย์ค้นหารายการขายผิดปกติที่ฝังไว้ในข้อมูล (Anomaly Detection)
- สั่ง Claude Code สร้างสคริปต์ daily-report ที่ query ยอดขายเมื่อวาน ประกอบเป็น Flex Message รายงานผู้บริหาร (พร้อม section แจ้งเตือนสีแดงเมื่อพบรายการผิดปกติ) แล้วส่งเข้ากลุ่มด้วย Push API โดยทดสอบด้วยโหมด dry-run ก่อนส่งจริง
- ตั้งเวลารันอัตโนมัติทุกเช้า 08:00 ด้วย Windows Task Scheduler พร้อมทดสอบสั่งรันทันที - จบ Workshop ทุกกลุ่มจะมีรายงานอัตโนมัติที่ทำงานเองได้จริง

### Session 4: Codex Cross-check, Governance และแนวทางต่อยอด (23:00 - 23:30)

- รัน workflow สรุปแชทและรายงานอัตโนมัติชุดเดียวกันบน GPT Codex เปรียบเทียบขั้นตอนการตั้งค่า MCP และผลลัพธ์
- Governance และ Privacy: การขอความยินยอมก่อนเก็บแชทกลุ่ม การใช้ read-only user กับฐานข้อมูลจริง ข้อมูลอ่อนไหวที่ห้ามส่งออกนอกองค์กร และการดูแล Token
- แนวทางต่อยอดหลังคอร์ส: สร้าง MCP Server ของตัวเอง, Alert เฉพาะเหตุการณ์ผิดปกติ, รายงาน HTML ประจำสัปดาห์ และการย้ายระบบขึ้น Cloud
- ถาม-ตอบปิดคอร์ส และแจกไฟล์เอกสาร prompt ทั้งหมดพร้อม checklist การนำไปใช้กับองค์กรจริง

## เรียนจบแล้วได้อะไร

- **ระบบที่ใช้งานได้จริงทันที 3 ระบบ:** บอทแจ้งเตือน HR และประกาศภายใน, ระบบสรุปแชทกลุ่มพร้อมติดตามงาน และรายงานธุรกิจอัตโนมัติเข้ากลุ่มผู้บริหาร ทั้งหมดสร้างด้วยมือผู้เรียนเอง
- **ทักษะ MCP ที่นำไปใช้ได้กว้าง:** เข้าใจหลักการเชื่อม AI Agent เข้ากับระบบภายนอกผ่าน MCP ซึ่งเป็นมาตรฐานเดียวกับที่ใช้เชื่อมฐานข้อมูล, GitHub, Google Drive และระบบองค์กรอื่น
- **สถาปัตยกรรมที่ถูกต้อง:** ออกแบบระบบ Webhook + ฐานข้อมูล + MCP ที่แก้ข้อจำกัดของ LINE Platform ได้อย่างเป็นระบบ ไม่ใช่แค่ทำตามสูตร
- **Prompt Library ฉบับองค์กรไทย:** ชุด prompt ภาษาไทยสำเร็จรูปทุก Workshop ที่ปรับใช้กับงานจริงได้ทันที และใช้ได้ทั้ง Claude Code และ GPT Codex
- **ความเข้าใจเรื่อง Automation อย่างยั่งยืน:** แยกได้ว่างานแบบไหนควรสั่ง AI สด งานแบบไหนควรเป็นสคริปต์ตั้งเวลา และวิธีเปลี่ยนงานมือให้เป็นระบบอัตโนมัติทีละขั้น
- **แนวปฏิบัติด้าน Privacy และ Governance:** รู้ขอบเขตที่ควรทำและไม่ควรทำ เมื่อนำข้อมูลแชทและข้อมูลธุรกิจขององค์กรมาประมวลผลด้วย AI
