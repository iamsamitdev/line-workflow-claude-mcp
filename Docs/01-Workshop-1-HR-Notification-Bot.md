**Day 1 · 21:40 - 22:20 (40 นาที)**

## เป้าหมายของ Workshop

จบ Workshop นี้ผู้เรียนจะ

1. มี LINE Official Account ของตัวเองที่เชื่อมกับ Claude Code ผ่าน MCP สำเร็จ
2. สั่ง AI ส่งข้อความเข้า LINE ด้วยประโยคภาษาไทยประโยคเดียว
3. ใช้เครื่องมือของ line-bot-mcp-server ได้ครบชุดขาส่ง: push, broadcast, flex
4. รู้จักดึงข้อมูลฝั่ง OA: `get_profile`, `get_follower_ids`, `get_message_quota`
5. เข้าใจว่าโควต้าข้อความมีจำกัด และต้องคิดก่อนกด broadcast

## Part A: ลงทะเบียน LINE Bot MCP เข้า Claude Code (8 นาที)

### A1. หา userId ของตัวเอง

เครื่องมือ `push_text_message` ต้องรู้ปลายทาง วิธีที่เร็วที่สุดในคลาสคือใช้ค่า `DESTINATION_USER_ID`
ซึ่งหาได้จาก LINE Developers Console > tab **Basic settings** > **Your user ID**

### A2. เพิ่ม MCP

Windows (Command Prompt):

```cmd
claude mcp add line-bot ^
  -e NPM_CONFIG_IGNORE_SCRIPTS=true ^
  -e CHANNEL_ACCESS_TOKEN=โทเคนของคุณ ^
  -e DESTINATION_USER_ID=userIdของคุณ ^
  -- npx -y @line/line-bot-mcp-server
```

macOS / Linux:

```bash
claude mcp add line-bot \
  -e NPM_CONFIG_IGNORE_SCRIPTS=true \
  -e CHANNEL_ACCESS_TOKEN=โทเคนของคุณ \
  -e DESTINATION_USER_ID=userIdของคุณ \
  -- npx -y @line/line-bot-mcp-server
```

### A3. ตรวจสถานะ

เปิด `claude` แล้วพิมพ์ `/mcp` ต้องเห็น `line-bot` เป็น **connected**
ถ้าไม่ขึ้น ให้ตรวจ 3 อย่างตามลำดับ: Node เวอร์ชัน, token ถูกวางครบไม่ตกอักขระ, ไม่มีเครื่องหมายคำพูดเกินมา

## Part C: งานจริงของฝ่าย HR (25 นาที)

ทำตามลำดับ อย่าข้าม เพราะแต่ละข้อสอนเครื่องมือคนละตัว

### C1. แจ้งนัดประชุมรายบุคคล (push_text_message)

```
ผมเป็นเจ้าหน้าที่ HR ของบริษัทสยามสมาร์ทเทรด
ช่วยส่งข้อความแจ้งนัดประชุมเข้า LINE ให้ผม โดยมีเนื้อหาว่า
- เรื่อง: ประชุมทบทวนแผนอัตรากำลังไตรมาส 3
- วันเวลา: วันจันทร์ที่ 10 สิงหาคม 2569 เวลา 09:00 - 10:30
- สถานที่: ห้องประชุมชั้น 3 อาคารสำนักงานใหญ่
- สิ่งที่ต้องเตรียม: ตัวเลขพนักงานเข้าออกเดือนกรกฎาคม
เขียนให้สุภาพ กระชับ อ่านง่ายบนมือถือ ใช้การเว้นบรรทัดแทน bullet เพราะ LINE ไม่รองรับ markdown
```

**จุดสอน:** ข้อความ text ของ LINE ไม่เรนเดอร์ markdown ดังนั้น `**ตัวหนา**` จะโชว์ดาวจริง ๆ
ต้องออกแบบด้วยการเว้นบรรทัดและสัญลักษณ์ธรรมดา

### C2. ดูว่ามีใครติดตาม OA อยู่บ้าง (get_follower_ids + get_profile)

```
ช่วยดูว่ามีผู้ติดตาม LINE OA ของผมกี่คน แสดง userId ทั้งหมด
แล้วดึงชื่อโปรไฟล์ของแต่ละคนออกมาให้ด้วย สรุปเป็นตาราง
```

**จุดสอน:**
- `get_follower_ids` คืนแต่ userId ไม่มีชื่อ ต้องเรียก `get_profile` ต่ออีกทีละคน
- นี่คือเหตุผลที่ระบบจริงต้องมีฐานข้อมูลของตัวเอง ไม่ควรเรียก API ทุกครั้ง
- OA ที่เพิ่งสร้างจะมีผู้ติดตามแค่ตัวเราคนเดียว ถือว่าปกติ

### C3. ตรวจโควต้าก่อนยิง broadcast (get_message_quota)

```
ตรวจโควต้าข้อความของ LINE OA ผมว่าเดือนนี้ส่งได้อีกกี่ข้อความ
และใช้ไปแล้วเท่าไหร่ บอกเป็นตัวเลขชัด ๆ
```

**จุดสอน (สำคัญมาก):** Free plan ส่ง push/broadcast ได้ **200 ข้อความต่อเดือน**
และ broadcast 1 ครั้งนับเป็นจำนวนผู้รับ ไม่ใช่ 1 ดังนั้นในคลาสให้ broadcast ครั้งเดียวเท่านั้น

### C4. ประกาศวันหยุดบริษัทแบบ broadcast (broadcast_text_message)

```
ช่วย broadcast ประกาศวันหยุดบริษัทถึงผู้ติดตาม LINE OA ทุกคน
เนื้อหา: บริษัทกำหนดวันหยุดพิเศษเพิ่มเติมวันจันทร์ที่ 10 สิงหาคม 2569
ฝ่ายจัดส่งยังทำงานตามปกติ สอบถามเพิ่มเติมติดต่อฝ่ายบุคคล เบอร์ภายใน 101
ลงท้ายว่า "ฝ่ายบุคคลและธุรการ บริษัทสยามสมาร์ทเทรด"
ก่อนส่งให้แสดงข้อความที่จะ broadcast ให้ผมอ่านยืนยันก่อน
```

**จุดสอน:** การให้ AI "แสดงก่อนส่ง" คือ pattern สำคัญของงาน automation จริง
เรียกว่า human-in-the-loop ควรใส่ในทุก prompt ที่ทำอะไรถาวรหรือส่งถึงคนหมู่มาก

### C5. Flex Message ประกาศรับสมัครงานภายใน (push_flex_message)

```
ช่วยออกแบบและส่ง Flex Message ประกาศรับสมัครงานภายใน (internal job posting) เข้า LINE ให้ผม
รายละเอียด
- ตำแหน่ง: หัวหน้าแผนกคลังสินค้า สาขาขอนแก่น
- คุณสมบัติ: ประสบการณ์คลังสินค้า 3 ปีขึ้นไป, ใช้ Excel ได้ดี, ขับรถยนต์ได้
- ปิดรับสมัคร: 20 สิงหาคม 2569
- ติดต่อ: ฝ่ายบุคคล เบอร์ภายใน 101
ดีไซน์: bubble ขนาด mega ส่วนหัวพื้นหลังสีเขียว LINE (#06C755) ตัวอักษรขาว
ในเนื้อหาแสดงคุณสมบัติเป็นรายการ มีปุ่มด้านล่างข้อความ "สมัครตำแหน่งนี้"
ที่ลิงก์ไปยัง https://www.itgenius.co.th
altText ให้เป็น "ประกาศรับสมัครงานภายใน: หัวหน้าแผนกคลังสินค้า"
```

**จุดสอน:**
- Flex Message คือ JSON โครงสร้าง box/text/button ไม่ใช่ HTML
- `altText` จำเป็นเสมอ เพราะเป็นสิ่งที่แสดงใน notification และรายการแชท
- ปุ่มแบบ `uri` ต้องเป็น **https** เท่านั้น (http จะ error)

### C6. ตรวจงานด้วย Flex Message Simulator

```
แสดง JSON ของ Flex Message ที่เพิ่งส่งไปให้ผมดูแบบเต็ม เพื่อผมจะเอาไปวางใน Flex Simulator
```

เอา JSON ไปวางที่ https://developers.line.biz/flex-simulator/
แล้วลองปรับสี ปรับขนาด ปรับ layout ด้วยมือ จะเข้าใจโครงสร้างเร็วขึ้นมาก

## Part D: โจทย์ท้าทายสำหรับ Developer (ทำเมื่อเสร็จก่อนเพื่อน)
