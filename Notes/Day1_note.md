### 1.2 AI Chat ต่างจาก AI Agent อย่างไร

นี่คือเส้นแบ่งที่ผู้เรียนต้องแยกให้ออกตั้งแต่นาทีแรก

```
AI Chat (สิ่งที่คนส่วนใหญ่ใช้):        AI Agent (สิ่งที่เราจะใช้วันนี้):
┌──────────────────────────────┐      ┌──────────────────────────────┐
│ คน  ──ถาม──►  AI            │      │ คน ──สั่ง──► AI Agent        │
│      ◄─ตอบเป็นข้อความ─       │  ⟶  │              │ วางแผน        │
│                              │      │              ▼               │
│ คนต้องเอาคำตอบไปทำเองต่อ      │      │        เรียกเครื่องมือจริง    │
│ (copy-paste, กดปุ่มเอง)      │      │        อ่านไฟล์ / รัน คำสั่ง  │
│                              │      │        ยิง API / เขียนโค้ด    │
└──────────────────────────────┘      └──────────────────────────────┘
   ได้ "คำตอบ"                            ได้ "ผลลัพธ์ที่เกิดขึ้นจริง"
```

| ประเด็น | AI Chat | AI Agent |
| --- | --- | --- |
| ผลลัพธ์ | ข้อความ | การกระทำจริงในระบบ |
| เข้าถึงไฟล์ในเครื่อง | ไม่ได้ | ได้ |
| รันคำสั่ง / ติดตั้ง package | ไม่ได้ | ได้ |
| เรียก API ภายนอก | ไม่ได้ (เว้นแต่มี tool) | ได้ผ่าน MCP |
| ทำงานหลายขั้นต่อเนื่อง | ต้องบอกทีละขั้น | วางแผนเองแล้วทำต่อกันได้ |
| ตัวอย่าง | Claude.ai, ChatGPT บนเว็บ | **Claude Code**, **GPT Codex CLI** |

> ✅ **ประโยคสรุปที่ใช้อธิบายให้ผู้บริหารฟังได้:** AI Chat คือ "ที่ปรึกษาที่พูดเก่ง" ส่วน AI Agent คือ "พนักงานที่ลงมือทำได้จริง" และ MCP คือ "ใบอนุญาตพร้อมกุญแจ" ที่เราให้พนักงานคนนั้นเข้าไปทำงานในระบบของเรา

### 1.3 Model Context Protocol (MCP) คืออะไร

ปัญหาก่อนมี MCP คือ AI แต่ละตัวต่อกับระบบภายนอกด้วยวิธีของตัวเอง ถ้ามี AI 3 ตัวและระบบ 5 ระบบ ต้องเขียนตัวเชื่อม 15 ชุด

```
ก่อนมี MCP (N x M):                    หลังมี MCP (N + M):

Claude ──┬──► LINE                     Claude ──┐
         ├──► Postgres                 Codex   ─┼──► [ MCP มาตรฐานกลาง ]
         └──► GitHub                   ตัวอื่น  ─┘          │
Codex  ──┬──► LINE                                    ┌─────┼─────┐
         ├──► Postgres                                ▼     ▼     ▼
         └──► GitHub                              LINE  Postgres GitHub
ตัวอื่น ──┬──► LINE
         ├──► Postgres
         └──► GitHub
   เขียนตัวเชื่อม 3 x 3 = 9 ชุด              เขียน MCP Server ระบบละ 1 ชุด (3 ชุด)
```

**MCP (Model Context Protocol)** คือมาตรฐานเปิดที่กำหนดว่า AI Agent จะคุยกับระบบภายนอกด้วยรูปแบบใด ทำให้ MCP Server ตัวเดียวใช้ได้กับ AI Agent ทุกตัวที่รองรับมาตรฐานนี้ (Claude Code, Codex CLI, และอื่น ๆ)

องค์ประกอบที่ต้องรู้จัก 3 อย่าง

| องค์ประกอบ | หน้าที่ | ตัวอย่างในหลักสูตรนี้ |
| --- | --- | --- |
| **MCP Host / Client** | AI Agent ที่เรียกใช้เครื่องมือ | Claude Code, Codex CLI |
| **MCP Server** | โปรแกรมที่ห่อ API ของระบบหนึ่งให้เป็นเครื่องมือมาตรฐาน | `@line/line-bot-mcp-server`, `@modelcontextprotocol/server-postgres` |
| **Tools** | ฟังก์ชันที่ MCP Server เปิดให้เรียก พร้อมคำอธิบายว่าใช้ทำอะไร | `push_text_message`, `get_message_quota` |

> 📖 **อ้างอิง:** สเปกและรายชื่อ MCP Server ที่มีอยู่ดูได้ที่ https://modelcontextprotocol.io/ ส่วนวิธีเพิ่ม MCP เข้า Claude Code อยู่ที่ https://docs.claude.com/en/docs/claude-code/mcp

### 1.4 เจาะเครื่องมือทั้ง 12 ตัวของ line-bot-mcp-server (v0.5.0)

นี่คือ "กล่องเครื่องมือ" ที่เราจะใช้ตลอดวันนี้ แบ่งได้ 3 กลุ่มชัดเจน

| กลุ่ม | เครื่องมือ | ใช้ทำอะไร | ได้ลองตอนไหน |
| --- | --- | --- | --- |
| **ส่งข้อความ** | `push_text_message` | ส่งข้อความ text ถึง user หรือ group ที่ระบุ | Workshop 1 ข้อ C1 |
| | `push_flex_message` | ส่ง Flex Message ถึง user หรือ group | Workshop 1 ข้อ C5 |
| | `broadcast_text_message` | ส่ง text ถึงผู้ติดตาม OA ทุกคน | Workshop 1 ข้อ C4 |
| | `broadcast_flex_message` | ส่ง Flex ถึงผู้ติดตามทุกคน | โจทย์ท้าทาย |
| **ข้อมูล** | `get_profile` | ดึงชื่อและรูปโปรไฟล์ของ user | Workshop 1 ข้อ C2 |
| | `get_follower_ids` | ดึงรายชื่อ userId ของผู้ติดตามทั้งหมด | Workshop 1 ข้อ C2 |
| | `get_message_quota` | ตรวจโควต้าข้อความคงเหลือของเดือนนี้ | Workshop 1 ข้อ C3 |
| **Rich Menu** | `get_rich_menu_list` | ดูรายการ rich menu ที่มีอยู่ | Workshop 2 ข้อ B1 |
| | `create_rich_menu` | สร้างโครง rich menu ใหม่ | Workshop 2 ข้อ B2 |
| | `delete_rich_menu` | ลบ rich menu | Workshop 2 ข้อ B5 |
| | `set_rich_menu_default` | ตั้งเป็นเมนูหลักของบัญชี | Workshop 2 ข้อ B3 |
| | `cancel_rich_menu_default` | ยกเลิกเมนูหลัก | Workshop 2 ข้อ B5 |

> ⚠️ **สังเกตให้ดี: ไม่มีเครื่องมือใดใน 12 ตัวนี้ที่อ่านประวัติแชทได้เลย** จำประโยคนี้ไว้ให้แม่น เพราะมันคือโจทย์ทั้งหมดของวันที่ 2

### 2.5 ลงทะเบียน LINE Bot MCP เข้ากับ Claude Code

**Windows (Command Prompt)** - เครื่องหมาย `^` คือการขึ้นบรรทัดใหม่ของคำสั่งเดียวกัน

```cmd
claude mcp add line-bot ^
  -e NPM_CONFIG_IGNORE_SCRIPTS=true ^
  -e CHANNEL_ACCESS_TOKEN=โทเคนของคุณ ^
  -e DESTINATION_USER_ID=userIdของคุณ ^
  -- npx -y @line/line-bot-mcp-server
```

**macOS / Linux** - เปลี่ยน `^` เป็น `\`

```bash
claude mcp add line-bot \
  -e NPM_CONFIG_IGNORE_SCRIPTS=true \
  -e CHANNEL_ACCESS_TOKEN=โทเคนของคุณ \
  -e DESTINATION_USER_ID=userIdของคุณ \
  -- npx -y @line/line-bot-mcp-server
```

**แกะคำสั่งทีละส่วน**

| ส่วน | ความหมาย |
| --- | --- |
| `claude mcp add line-bot` | เพิ่ม MCP Server ชื่อเล่นว่า `line-bot` (ชื่อนี้ใช้อ้างใน prompt ได้) |
| `-e NPM_CONFIG_IGNORE_SCRIPTS=true` | สั่ง npm ข้าม post-install script ทำให้ติดตั้งเร็วขึ้นและปลอดภัยขึ้น |
| `-e CHANNEL_ACCESS_TOKEN=...` | กุญแจที่ MCP ใช้ยิง Messaging API |
| `-e DESTINATION_USER_ID=...` | ปลายทางเริ่มต้นเมื่อ prompt ไม่ได้ระบุปลายทาง |
| `-- npx -y @line/line-bot-mcp-server` | คำสั่งจริงที่ใช้รัน MCP Server (`--` คือเส้นแบ่งระหว่าง option กับคำสั่ง) |

> 💡 **เกร็ดที่มีประโยชน์มาก:** ถ้าเพิ่ม MCP แล้วเปลี่ยนโฟลเดอร์แล้วหาย เพราะค่าเริ่มต้นผูกกับโฟลเดอร์ ให้เพิ่ม `-s user` ต่อท้ายชื่อ (เช่น `claude mcp add line-bot -s user ...`) จะใช้ได้ทุกโฟลเดอร์ในเครื่อง

### ขั้นที่ 5 - Flex Message ประกาศรับสมัครงานภายใน (`push_flex_message`)

**Flex Message คืออะไร:** คือข้อความที่จัดวางองค์ประกอบเองได้ (กล่อง ข้อความ รูป ปุ่ม) ส่งเป็น **JSON** ไม่ใช่ HTML โครงสร้างหลักมี 4 ส่วน

```
bubble (การ์ด 1 ใบ)
├── header   ส่วนหัว (มักใส่สีพื้นหลังแบรนด์)
├── hero     รูปภาพใหญ่ (ไม่บังคับ)
├── body     เนื้อหาหลัก (box ซ้อน box ซ้อน text)
└── footer   ปุ่มหรือข้อความปิดท้าย

carousel = เอา bubble หลายใบมาเรียงกันเลื่อนซ้ายขวาได้ (สูงสุด 12 ใบ)
```

**Prompt**

```
ช่วยออกแบบและส่ง Flex Message ประกาศรับสมัครงานภายใน (internal job posting) เข้า LINE ให้ผม
รายละเอียด
- ตำแหน่ง: หัวหน้าแผนกคลังสินค้า สาขาขอนแก่น

- ปิดรับสมัคร: 20 สิงหาคม 2569
- ติดต่อ: ฝ่ายบุคคล เบอร์ภายใน 101
ดีไซน์: bubble ขนาด mega ส่วนหัวพื้นหลังสีเขียว LINE (#06C755) ตัวอักษรขาว

ที่ลิงก์ไปยัง https://www.itgenius.co.th
altText ให้เป็น "ประกาศรับสมัครงานภายใน: หัวหน้าแผนกคลังสินค้า"
```

> 🎓 **จุดสอน 3 ข้อ:**
> 1. Flex Message คือ **JSON** โครงสร้าง box/text/button ไม่ใช่ HTML และไม่มี CSS
> 2. `altText` **จำเป็นเสมอ** เพราะเป็นข้อความที่แสดงใน notification และในรายการแชท ถ้าตั้งไม่ดีผู้รับจะไม่รู้ว่าข้อความเรื่องอะไร

**โครงสร้าง JSON ตัวอย่างที่ AI ควรสร้างให้ (ย่อ)**

```json
{
  "type": "bubble",
  "size": "mega",
  "header": {
    "type": "box",
    "layout": "vertical",
    "backgroundColor": "#06C755",
    "paddingAll": "16px",
    "contents": [
      { "type": "text", "text": "ประกาศรับสมัครงานภายใน", "color": "#FFFFFF", "weight": "bold", "size": "lg" }
    ]
  },
  "body": {
    "type": "box",
    "layout": "vertical",
    "spacing": "md",
    "contents": [
      { "type": "text", "text": "หัวหน้าแผนกคลังสินค้า สาขาขอนแก่น", "weight": "bold", "wrap": true }
    ]
  },
  "footer": {
    "type": "box",
    "layout": "vertical",
    "contents": [
      {
        "type": "button",
        "style": "primary",
        "color": "#06C755",
        "action": { "type": "uri", "label": "สมัครตำแหน่งนี้", "uri": "https://www.itgenius.co.th" }
      }
    ]
  }
}
```

- Windows: `%USERPROFILE%\.codex\config.toml`
- macOS / Linux: `~/.codex/config.toml`

เพิ่มบล็อกนี้เข้าไป

```toml
[mcp_servers.line-bot]
command = "npx"
args = ["-y", "@line/line-bot-mcp-server"]

[mcp_servers.line-bot.env]
NPM_CONFIG_IGNORE_SCRIPTS = "true"
CHANNEL_ACCESS_TOKEN = "โทเคนของคุณ"
DESTINATION_USER_ID = "userIdของคุณ"
```

แล้วเปิด `codex` ใหม่ ตรวจว่าเห็น tool ของ line-bot

> ⚠️ **จุดพลาดที่พบบ่อย:** แก้ไฟล์ผิดที่ หรือ syntax TOML ผิด (ต้องมีวงเล็บเหลี่ยม `[mcp_servers.line-bot]` และค่าที่เป็นข้อความต้องครอบด้วย `"`) และต้องปิดเปิด codex ใหม่ทุกครั้งที่แก้ config

### 🌉 สะพานเชื่อมสู่วันที่ 2

วันนี้เราทำได้แค่ **"ขาส่ง"** คือสั่ง AI ส่งข้อความออกไป แต่ AI ยัง **"อ่าน"** อะไรจาก LINE ไม่ได้เลย

```
วันที่ 1 (ทำแล้ว):                    วันที่ 2 (จะทำพรุ่งนี้):

Claude Code ──MCP──► LINE            LINE ──Webhook──► เซิร์ฟเวอร์ของเรา
   (ขาส่งอย่างเดียว)                             │
                                                 ▼
                                            PostgreSQL (หน่วยความจำ)
                                                 │
                                    Claude Code ─┴─► วิเคราะห์ + ส่งกลับ
                                       (ครบทั้งขาอ่านและขาส่ง)
```

พรุ่งนี้เราจะสร้าง Webhook Server เก็บแชทกลุ่มลง PostgreSQL ให้ AI อ่านผ่าน Postgres MCP แล้วสรุปส่งกลับเข้ากลุ่ม และปิดท้ายด้วยรายงานธุรกิจที่รันเองทุกเช้าโดยไม่มีคนสั่ง
